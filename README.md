A make.fun one-liner entry for **The Houseplant Out-of-Office**: the funniest
out-of-office auto-reply a houseplant would send, in 120 characters or fewer.

`main.py` (Python standard library only, deterministic, no network) writes the
entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Out of office: I'm a fern. You haven't watered me since March, so now I'm drinking your unread emails. Good luck.

The fern has been ignored since March — so it stopped waiting for water and
started drinking the unread emails instead.
